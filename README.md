# App IBR (Igreja Batista Restauração, Timon-MA)

PWA da igreja: agenda, avisos, devocional, membros, liderança, finanças e fotos.
Front-end estático (`index.html`) + Supabase (login, banco e regras de segurança em `schema.sql`).

Publicação: GitHub Pages (branch `main`, raiz). Domínio próprio via arquivo `CNAME`.
